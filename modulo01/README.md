# Sistema de Vendas para Açaiteria 🍦

Este projeto é um sistema em Python desenvolvido para gerenciar e simular as operações de vendas de uma açaiteria. Ele foi projetado levando em consideração as perspectivas de diferentes stakeholders do negócio, como o Product Owner (PO), Clientes (QA), Desenvolvedores (Tech/Dev), UX Designers e Analistas de Dados (IA).

## 🎯 Objetivos do Projeto (Perspectivas)

*   **PO (Dono do negócio):** Disponibilizar os produtos virtualmente através de um sistema de vendas.
*   **QA (Cliente):** Comparar produtos com qualidade e praticidade.
*   **Tech (Programador):** Desenvolver um software eficiente e funcional para o negócio.
*   **Dev (Programador):** Implementar as funcionalidades necessárias para atender às necessidades do negócio e dos clientes.
*   **UX (Designer de Experiência):** Criar uma interface intuitiva e agradável para garantir uma experiência de compra satisfatória.
*   **IA (Analista de Dados):** Coletar e analisar dados de acesso para identificar erros e aprimorar o sistema.

## 🚀 Funcionalidades

O sistema opera via terminal de comando (CLI) e oferece um menu interativo com as seguintes opções:

1.  **Cadastrar produto:** Permite ao usuário cadastrar até 5 produtos diferentes, definindo:
    *   Nome
    *   Quantidade em estoque
    *   Preço
    *   Data de validade
    *   Descrição do produto
2.  **Listar produtos:** Exibe todos os produtos cadastrados atualmente no sistema, mostrando seus detalhes (nome, preço, estoque, validade e descrição).
3.  **Selecionar produto:** (Em desenvolvimento) Opção para selecionar um produto específico.
4.  **Cadastrar pagamento:** (Em desenvolvimento) Opção para definir a forma de pagamento.
5.  **Confirmar compra:** Simula a confirmação ou o cancelamento de uma compra pelo cliente.
6.  **Realizar venda:** Finaliza a transação de venda.
7.  **Sair:** Encerra a execução do programa.

## 📦 Produtos Pré-Cadastrados

O sistema já inicia com 5 opções de açaí pré-configuradas no código fonte:

*   Açaí comum
*   Açaí premium
*   Açaí personalizável
*   Açaí puro
*   Açaí com Morango

*Nota: Estes produtos podem ser sobrescritos utilizando a opção "1" do menu.*

## 🛠️ Como Executar

1.  Certifique-se de ter o Python instalado em sua máquina.
2.  Clone este repositório ou baixe o arquivo `.py`.
3.  Abra o terminal ou prompt de comando.
4.  Navegue até o diretório onde o arquivo está salvo.
5.  Execute o comando: `python nome_do_arquivo.py` (substitua `nome_do_arquivo.py` pelo nome real do seu arquivo Python).
